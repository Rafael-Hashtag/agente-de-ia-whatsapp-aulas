# Agente de Vendas no WhatsApp

Se a pessoa pediu para instalar, configurar ou digitou `INICIAR SETUP`: leia
[INSTALACAO.md](INSTALACAO.md) inteiro e siga o roteiro. Não monte um bot do zero: o
produto já está pronto neste repositório.

Se o pedido for para **desenvolver** o projeto (corrigir bug, nova funcionalidade), a
estrutura está no README (seção "Para desenvolvedores"). Rode `pytest` depois de qualquer
mudança e mantenha os nomes e comentários em português, como no resto do código.
